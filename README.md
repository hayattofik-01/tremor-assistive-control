# Tremor-Canceling Assistive Device

A course-aligned simulation and numerical-validation project for **Optimization and
Machine Learning for Dynamical Systems**: a simplified nonlinear tremor-affected
assistive device, its linearized structural properties, classical/optimal/
constrained control (pole placement, LQR, linear MPC), a Luenberger observer,
neural-network and kernel-ridge system identification, and a data-reduction study.

This is a simulation and control study inspired by an assistive-technology
application. It makes no claim of medical, clinical, or physiological validity, and
involves no hardware or patient data.

## Setup

```bash
cd /Users/nat/Documents/oml-project
python3 -m venv .venv        # already created
source .venv/bin/activate
pip install -r requirements.txt
```

## Run everything

```bash
PYTHONPATH=. python3 experiments/run_all.py
```

This runs Experiments A–F in order and writes:
- figures to `results/figures/fig01_*.png` … `fig10_*.png`
- tables to `results/tables/*.csv` and `results/tables/summary.json`

Individual experiments can also be run on their own, e.g.
`PYTHONPATH=. python3 experiments/03_mpc.py`.

## Run tests

```bash
python3 -m pytest -q
```

## Project structure

```text
src/
  config.py              # single source of truth for plant/controller/experiment parameters
  dynamics.py             # nonlinear plant, RK4 integrator, linearization, tremor disturbance
  discretization.py        # zero-order-hold discretization for MPC
  analysis.py              # eigenvalues, controllability/observability
  controllers.py           # pole placement, continuous & discrete LQR, tracking state feedback
  observer.py               # Luenberger observer + closed-loop output-feedback simulation
  mpc.py                    # constrained linear MPC (CVXPY/OSQP)
  data_generation.py        # identification-trajectory generation, reference signals, splits
  nn_identifier.py           # MLP-based system identification
  kernel_identifier.py       # RBF kernel-ridge system identification
  data_reduction.py          # dataset subsampling for the data-efficiency study
  metrics.py                  # RMSE, tracking/tremor/effort/constraint/rollout metrics

experiments/
  01_core_analysis.py         # Experiment A: open loop, nonlinear vs. linear, eigenvalues
  02_control_comparison.py     # Experiment B: pole placement vs. LQR, Q/R sensitivity
  03_mpc.py                     # Experiment C: LQR vs. constrained MPC, observer
  04_system_identification.py    # Experiment D: NN vs. kernel one-step/rollout prediction
  05_generalization.py            # Experiment E: unseen disturbance condition
  06_data_reduction.py             # Experiment F: 100/50/20/10% training data
  run_all.py                        # runs all of the above and assembles result tables

results/figures/, results/tables/   # generated by run_all.py
tests/                                # pytest unit tests for every src module
```

## Scope note

This project deliberately stays within course scope: no real medical data, no EMG/
computer-vision processing, no full biomechanical arm model, no reinforcement
learning, no hardware.
